# v3NetbillAgent

Windows client agent untuk sistem billing warnet **v3Netbill**. Terhubung ke backend NestJS via Socket.IO (namespace `/session`).

## Arsitektur (FASE 7–9)

## Protokol Socket.IO (backend: `session.gateway.ts`)

**Namespace:** `/session` (di URI: `http://host:3000/session`)

| Arah | Event | Payload |
|------|-------|---------|
| Agent → Server | `agent:register` | `{ pcId, agentToken }` |
| Agent → Server | `agent:heartbeat` | `{ pcId }` (tiap 15 detik) |
| Agent → Server | `client:login_request` | `{ pcId, kredensial: { kode, password } }` |
| Server → Agent | `client:login_result` | `{ sukses, alasan?, durasiDetikTersedia? }` |
| Server → Agent | `session:start` | `{ sessionId, durasiDetikTersedia }` |
| Server → Agent | `session:tick` | `{ sisaDetik }` |
| Server → Agent | `session:stop` | `{ alasan }` |

Semua payload **camelCase**. `ServerConnection` memakai `SocketIOClient` v4.0.5 (System.Text.Json default).

## Service ↔ Overlay Communication (Named Pipe)

**Pipe name:** `v3netbill-agent` (duplex, message mode)

| Arah | Type | Payload |
|------|------|---------|
| Service → Overlay | `StateUpdate (1)` | `{locked, sessionId, durasiDetik, sisaDetik}` |
| | `SessionTick (4)` | `{sisaDetik}` |
| | `LoginResult (5)` | `{sukses, alasan?}` |
| | `PinVerifyResult (6)` | `{sukses}` |
| Overlay → Service | `LoginRequest (100)` | `{kode, password}` |
| | `PinVerifyRequest (101)` | `{pin}` |

## Lock Enforcement (FASE 8)

- **Registry TaskMgr block**: `HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\System\DisableTaskMgr = 1` (Locked) / `0` (Unlocked)
- **Watchdog**: Timer 5 detik cek `Agent.Overlay.exe` process saat Locked → restart jika mati
- **Keyboard Hook** (WH_KEYBOARD_LL): Blokir `Alt+Tab`, `LWin/RWin`, `Alt+F4` **hanya saat Locked**
- **TIDAK diblokir**: `Ctrl+Alt+Del` (Secure Attention Sequence — by design Windows)
- **Technician shortcut**: `Ctrl+Alt+Shift+F12` → PIN dialog → verify via `/api/settings/verify-pin` → disable hook temporarily

## Konfigurasi

`appsettings.json`:
```json
{
  "Server": { "Url": "http://localhost:3000" },
  "Agent": { "PcId": "PC001", "Token": "FROM_ADMIN_DASHBOARD" },
  "Overlay": { "ExePath": "" }
}
```
- `PcId` & `agentToken` didapat dari dashboard admin (PC terdaftar), **bukan** digenerate client.

## FASE 9: Installer & GitHub Actions

### 1. Push ke GitHub & Build Otomatis

```bash
# Inisialisasi git (repo ini belum ber-git)
git init
git add .
git commit -m "v3NetbillAgent FASE 7-9 complete"
git branch -M main
git remote add origin https://github.com/<USER>/<REPO>.git
git push -u origin main
```

**Trigger build**: Push ke branch `main` yang mengubah folder `v3NetbillAgent/**`, atau jalankan manual via **Actions → Build v3NetbillAgent → Run workflow**.

### 2. Download Hasil Build (.msi)

1. Buka tab **Actions** di repository GitHub
2. Klik workflow run terbaru (yang hijau/success)
3. Di bagian **Artifacts**, download `v3NetbillAgentSetup`
4. Extract zip → dapatkan `v3NetbillAgentSetup.msi`

### 3. Install di PC Client (Windows)

1. Jalankan `v3NetbillAgentSetup.msi` sebagai **Administrator** (klik kanan → Run as administrator)
2. Wizard akan muncul:
   - **Server Configuration** dialog: masukkan
     - **Server URL**: alamat backend v3Netbill (contoh: `http://192.168.1.100:3000`)
     - **PC ID**: ID PC dari dashboard admin (contoh: `PC001`)
     - **Agent Token**: token dari dashboard admin (generate saat daftarkan PC)
   - Next → Install
3. Setelah selesai:
   - **Agent.Service** terinstall sebagai Windows Service (auto-start, SYSTEM)
   - **Agent.Overlay** terinstall ke folder yang sama, dijadwalkan jalan saat user logon (Scheduled Task)
   - File `appsettings.json` di folder instalasi terisi dengan nilai yang diinput

### 4. Verifikasi Installasi

```powershell
# Cek service berjalan
Get-Service v3NetbillAgent

# Cek scheduled task
Get-ScheduledTask -TaskName v3NetbillAgentOverlay

# Cek file instalasi
ls "C:\Program Files\v3NetbillAgent\"
```

### 5. Uninstall Protection (Catatan Desain)

**Pendekatan: Application-level protection (bukan installer-level)**

Alasan:
- Windows MSI uninstall **tidak bisa diblokir andal** oleh custom action jaringan (network mungkin tidak tersedia, custom action bisa timeout/hang, user tetap bisa force-uninstall via `msiexec /x` atau tools pihak ke-3).
- Proteksi nyata yang dibutuhkan: mencegah user bypass lockscreen/TaskMgr block saat sesi aktif.
- **Solusi**: Agent.Service (SYSTEM) yang menegakkan proteksi:
  - `DisableTaskMgr = 1` saat Locked
  - Watchdog restart Overlay
  - Keyboard hook aktif
- Proteksi **hanya dilepas** saat:
  1. Sesi berakhir normal (server kirim `session:stop`), ATAU
  2. Teknisi verifikasi PIN via Overlay (`Ctrl+Alt+Shift+F12` → PIN → `/api/settings/verify-pin`)
- Jika uninstall via Control Panel: MSI hapus file/service/task → Service `OnStop()` set `DisableTaskMgr=0` → ini **diterima** karena uninstall berarti admin ingin hapus agent total. Jika uninstall jahat (user bypass lock), mereka butuh hak admin — dan jika sudah admin, mereka sudah kendali penuh mesin.

## Build Manual (Windows)

```powershell
# Prerequisites: .NET 8 SDK, WiX Toolset v4 (dotnet tool install --global wix)

# Restore & build
dotnet restore v3NetbillAgent.sln
dotnet build v3NetbillAgent.sln -c Release

# Publish self-contained
dotnet publish Agent.Service/Agent.Service.csproj -c Release -r win-x64 --self-contained -o artifacts/Agent.Service
dotnet publish Agent.Overlay/Agent.Overlay.csproj -c Release -r win-x64 --self-contained -o artifacts/Agent.Overlay

# Generate WiX fragments
heat dir artifacts/Agent.Service -cg ServiceComponents -gg -sfrag -srd -dr INSTALLFOLDER -var var.AgentServicePublishDir -out Installer/ServiceComponents.wxs
heat dir artifacts/Agent.Overlay -cg OverlayComponents -gg -sfrag -srd -dr INSTALLFOLDER -var var.AgentOverlayPublishDir -out Installer/OverlayComponents.wxs

# Build MSI
candle -dAgentServicePublishDir="artifacts\Agent.Service\" -dAgentOverlayPublishDir="artifacts\Agent.Overlay\" -ext WixToolset.Util.wixext -out Installer/ Installer/Product.wxs Installer/ServiceComponents.wxs Installer/OverlayComponents.wxs
light -ext WixToolset.Util.wixext -ext WixToolset.UI.wixext -out artifacts/v3NetbillAgentSetup.msi Installer/Product.wixobj Installer/ServiceComponents.wixobj Installer/OverlayComponents.wixobj
```
